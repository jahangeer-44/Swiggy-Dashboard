# 🍽️ Swiggy Dashboard

## 📌 Project Overview

The **Swiggy Dashboard** is a data analytics and visualization project
based on Swiggy-related data. The purpose of the project is to organize
data into meaningful visual reports and make it easier to explore
business performance and trends.

The dashboard is intended to help users examine the available data,
compare important measures, and identify patterns that can support
data-driven decisions.

## 🎯 Project Objectives

-   Explore and understand the Swiggy dataset.
-   Prepare the data for analysis.
-   Present important measures and trends through a dashboard.
-   Make it easier to compare categories and identify patterns.
-   Support clear, data-driven interpretation of the available
    information.
